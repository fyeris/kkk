AI Chat Studio - プロトタイプ

APIキーの入力や外部サーバーの構築を一切必要とせず、単一のHTMLファイルをブラウザで開くだけですぐに動作するスタンドアロン型AIチャットアプリケーションのプロトタイプです。

✨ 主な特徴

APIキー不要・即時起動: 内蔵のデモAI応答エンジンにより、外部APIとの通信なしでリッチな会話体験（Markdown整形、コードブロック、比較表など）をすぐにテストできます。

単一ファイル構成: HTML / CSS / JavaScript が index.html 1ファイルに完結しており、ローカル環境（file://）でもそのまま動作します。

背景デザイン＆テーマ切替: サイドバーから「オーロラ」「ミニマル」「ドット」の3種類の背景デザインと、ダーク／ライトモードをワンクリックで切り替えられます。

Markdown＆コードハイライト: 返答内の見出し・リスト・表を綺麗に描画し、プログラムコードにはシンタックスハイライトとワンクリックコピーボタンを自動付与します。

会話履歴の自動保存: 複数のチャットスレッドを作成・切り替え・削除でき、ブラウザのストレージ（制限時はメモリフォールバック）に自動保存されます。

🚀 使い方

index.html をダウンロード（または保存）します。

お好みのWebブラウザ（Chrome, Edge, Safari, Firefox など）で index.html を直接開きます。

画面中央のサジェストカードをクリックするか、下部の入力欄にメッセージを入力して Enter キーで送信します。

💡 リッチ表示を試すキーワード例

以下のキーワードを含めてメッセージを送信すると、専用のMarkdownレイアウトを確認できます。

「コード」 / 「JavaScript」: シンタックスハイライト＆コピーボタン付きのコードブロックを表示

「比較」 / 「表」: Markdownのテーブル（比較表）を表示

「アイデア」: 箇条書きの企画アイデアリストを表示

「プレスリリース」: ビジネス文書の構成テンプレートを表示

🛠 使用技術（CDNライブラリ）

Tailwind CSS: ユーティリティファーストのレスポンシブUI構築

Marked.js: MarkdownテキストからHTMLへの高速変換

DOMPurify: XSS（クロスサイトスクリプティング）対策のHTMLサニタイズ

Highlight.js: プログラムコードのシンタックスハイライト

Lucide Icons: モダンで軽量なSVGアイコンセット

🎨 カスタマイズ方法

本番用のLLM API（Gemini API等）と接続したい場合

index.html 内の handleSendMessage 関数内にある generateLocalAIResponse() の呼び出し部分を、実際の fetch() によるAPIリクエスト処理に置き換えることで、本番用のAIチャットアプリへ拡張できます。
